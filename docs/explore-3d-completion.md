日期：2026-09-12。入口：http://127.0.0.1:4174/explore 。本轮交付桌面端，依据用户的 3D Explore 需求及两份质量要求完成；用户此前明确“不用管手机端”，手机端不列入验收。

## 完成内容

`/explore` 已从系统图切换页升级为可旋转、缩放、点选的 3D AI 系统空间。默认仅显示 User、Context、Model、Harness、External World、Final 六个核心，模块层显示 12 个节点，细节层包含 56 个概念。节点的位置表达所属区域，连线表达信息、执行与反馈关系。

- A：多层模型、透明 Context、Memory 存储仓、RAG 筛选结构、Harness 底座和外围能力；节点选择、相机聚焦、详情面板。
- B：有向连接、上下游高亮、三层展开、相关概念临时显示；标签预算与碰撞避让、相机范围和全景返回。
- C：17 步 GPU 研究教学模拟，包含请求、执行、结果回到 Context、检查失败、Agent Loop、补充证据、再次检查及交付；完整播放、暂停、前后步、时间线和重播。
- D：搜索、六组概念导航、13 站系统导览、课程状态三态、原课程入口、键盘、减少动态效果、后台暂停及 WebGL 故障替代入口。

Explore 只读取学习进度。所有概念可自由探索，深入课程仍遵循现有学习地图的解锁规则。没有新增课程、成绩写入或外部真实执行。

## 知识和教学边界

定义复用已有 `final-system-map/concepts.ts`。Model 生成下一步请求，Harness 执行调度；MCP 是可选连接路径；Memory 与 RAG 提供相关信息给 Context；工具结果进入 Context 后供 Model 继续判断；FAIL 返回 Loop，PASS 后才进入 Final。State 与 Trace 分开，并表达运行过程中持续记录。

所有执行和资料来源均标明教学模拟。导览与任务用于建立系统关系，不是新的考试。没有开展真人 5 秒、10 秒、30 秒研究，不能以技术验收推断真实新手的理解率。

## 工程范围

新增实现集中于 `src/features/explore-3d/`，原 `src/pages/Explore/ExplorePage.tsx` 变为薄入口。场景按相机、环境、节点几何、连接、标签避让拆分，复用现有 `SceneCanvas` 的 WebGL 检查和清理。沿用 React、R3F、Drei、Three.js，无新增依赖。

模式、节点、展开深度、导览/任务步骤和手动视角通过 URL 保存；搜索文字保持页面局部状态。相机动画与任务计时器不写入全站 Store。静止状态按需渲染，只让当前任务的活动连接流动。

## 审查发现与修复

独立审查见 [explore-3d-review.md](explore-3d-review.md)。已修复：

1. 缩放结束时分别保存深度和视角会丢失深度：改为一次更新，保留回归测试。
2. 3D 标签未区分课程可学和锁定：统一 Check / Circle / Lock 三态与可访问名称，锁定概念仍可点选。
3. 真实节点点击和 Orbit 结束事件争抢 URL：无位移点击不保存相机；标签隔离指针事件；控制器合并同一轮参数更新，避免用户选择丢失。
4. 全景过小、连线偏淡、Model 聚焦时 Context 标签消失：调整相机和对比，优先保留相关核心，增加有限横向标签避让。
5. 跨系统任务路径可能超出镜头、高位节点目标超出 Pan 边界：按活动连接端点取景，提前约束相机目标。

### 实际性能采样

在当前 Windows 机器的内置浏览器、生产构建、1440×900 CSS 视口、L2 完整展开并播放任务时，累计 5 秒活动帧采样约 **60 FPS / 265 Draw Calls / 19,368 Triangles**。较窄的 1054×652 生产面板另一次采样为 60 FPS / 248 Draw Calls / 18,824 Triangles。默认 L0 开发检查采样约 57 FPS。数值通过渲染器采样回调输出到开发 DOM，不把按需渲染的空闲时间计入帧率。

这些是当前机器与当前任务阶段的采样，不代表所有显卡、全部路径的最低帧率或低配保证。未实施 CPU 降速。动态对象仅出现在活动连接，暂停后停止推进；GPU 故障时可继续使用文字导航。

开发时向正在运行的控制器添加 Hook，HMR 曾产生一次旧 Hook 顺序错误；完整刷新后消失。生产页面单独检查未出现运行错误，历史开发日志未被计为生产错误。
